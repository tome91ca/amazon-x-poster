# X ポストジェネレーター 🛡️📦→𝕏

防災ポストとAmazon商品紹介ポストを、Gemini AIで自動生成するWebアプリです。

## ✨ 機能

### 🛡️ 防災ポスト生成
- 8つのテーマ（地震、台風、火災、備蓄、避難、家族、日常など）
- 6つの形式（豆知識、チェックリスト、クイズ、ストーリー、注意喚起、季節）
- 公的機関の情報をベースに最新情報をAIが生成
- 季節に合わせた内容を自動調整

### 📦 Amazon商品ポスト生成
- AmazonのURLからレビューをAIが分析
- 3つのトーン（おすすめ系、情報系、辛口系）から選択
- 3パターンの投稿文を自動生成
- アソシエイトリンク自動生成

### 🐦 共通機能
- Xに直接投稿（投稿画面が開く）
- ワンクリックでコピー
- スマホ・PC両対応のレスポンシブデザイン

## 🚀 デプロイ手順

### 1. Gemini APIキーを取得
https://aistudio.google.com/apikey でキーを作成

### 2. GitHubにアップロード
このフォルダの**中身**をGitHubリポジトリにアップロード

### 3. Vercelにデプロイ
1. https://vercel.com でリポジトリをImport
2. Environment Variables に `GEMINI_API_KEY` を追加
3. Deploy

## 🔑 環境変数

| 変数名 | 説明 |
|--------|------|
| `GEMINI_API_KEY` | Google Gemini APIキー（必須） |
